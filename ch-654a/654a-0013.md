# 654A.13 Confidentiality.
If mediation is conducted pursuant to this chapter, the confidentiality of all mediation communications is protected as provided in section 679C.108.
Source note: 86 Acts, ch 1214, §26; 89 Acts, ch 108, §5; 90 Acts, ch 1143, §13, 14; 98 Acts, ch 1062, §11; 2005 Acts, ch 68, §4
