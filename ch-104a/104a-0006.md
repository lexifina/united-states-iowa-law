# 104A.6 Conformance with rules of state building code commissioner.
The authority responsible for the construction of any building or facility covered by section 104A.2 shall conform with rules adopted by the state building code commissioner as provided in section 103A.7.
Source note: [C66, 71, 73, 75, 77, 79, 81, §104A.6] 93 Acts, ch 95, §4
