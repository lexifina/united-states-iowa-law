# 256.190 Application for grants.
Each applicant, in accordance with the rules and regulations of the commission, shall:
(1) Complete and file an application for a tuition grant.
(2) Be responsible for the submission of the parents’ confidential statement for processing, the processed information to be returned both to the commission and to the college in which the applicant is enrolling.
(3) Report promptly to the commission any information requested.
(4) File a new application and parents’ confidential statement annually on the basis of which the applicant’s eligibility for a renewed tuition grant will be evaluated and determined.
Source note: [C71, 73, 75, 77, 79, 81, §261.16] 2023 Acts, ch 19, §2641C2024, §256.190
