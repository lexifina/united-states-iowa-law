# 2B.21 Availability of parts of the Iowa Code and administrative code.
The Iowa Code editor and the administrative code editor, in accordance with policies established by the legislative council, may cause parts of the Iowa Code or administrative code to be made available for the use of public officers and other persons. This authority shall be exercised in a manner planned to avoid delay in the other publications of the editors.
