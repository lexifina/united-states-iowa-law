# 29B.74 Principals.
Any person subject to this code is a principal if the person does any of the following:
(1) Commits an offense punishable by this code, or aids, abets, counsels, commands, or procures its commission.
(2) Causes an act to be done which if directly performed by the person would be punishable by this code.
Source note: [C66, 71, 73, 75, 77, 79, 81, §29B.74] 2006 Acts, ch 1010, §20
