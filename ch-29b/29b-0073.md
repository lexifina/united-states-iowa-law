# 29B.73 Persons to be tried or punished.
A person shall not be tried or punished for any offense provided for in this code unless it was committed while the person was in a duty status or during a time when the person was under lawful orders to be in a duty status.
Source note: [C66, 71, 73, 75, 77, 79, 81, §29B.73; 82 Acts, ch 1042, §42]
