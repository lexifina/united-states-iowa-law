# 4A.14 Minority representation.
All appointive boards, commissions, committees, and councils of the state established by the Code if not otherwise provided by law should provide, to the extent practicable, for minority representation. All appointing authorities of boards, commissions, committees, and councils subject to this section should consider qualified minority persons for appointment to boards, commissions, committees, and councils. For purposes of this section, “minority” means a minority person as defined in section 15.102.
