# 804.26 Officer’s return.
In all cases, the peace officer, when the officer takes a person committed to the officer under an order as provided in this chapter before a magistrate, either for the purpose of giving bail, if bail be taken, or for trial or preliminary examination, must make a return on such order, and sign such return with the officer’s name of office, and deliver the same to the magistrate.
