# 616.5 Resident — attachment.
Except as hereinafter provided, an action against a resident of this state must be brought in the county of the defendant’s residence, or that in which the contract was to be performed, except that, if an action be duly brought against such defendant in any other county by virtue of any of the provisions of this chapter, then such action may, if legal cause for an attachment exist, be aided by attachment.
