# 388.7 Prior utility board.
(1) A utility board functioning on July 1, 1975, shall continue to function until discontinued as provided in this chapter, and has all the powers granted in this chapter.
(2) Nothing in the city code shall be construed to allow the abrogation of any franchise.
Source note: [C75, 77, 79, 81, §388.7] 2019 Acts, ch 59, §114
