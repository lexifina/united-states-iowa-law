# 554B.1 Definitions.
As used in this chapter “transmitting utility” has the same meaning as defined in the Uniform Commercial Code, section 554.9102, subsection 1. Security interests filed pursuant to this chapter prior to January 1, 1975, which have not been terminated, are deemed to be filed in accordance with section 554.9501, subsection 2.
