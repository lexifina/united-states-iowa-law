# 349.4 Application — contest.
Any publisher who desires that the publisher’s newspaper be so selected may make written application therefor to the board of supervisors at any time prior to the making of the selection. If more applications are filed than there are newspapers to be selected, a contest shall exist.
Source note: [C24, 27, 31, 35, 39, §5400; C46, 50, 54, 58, 62, 66, 71, 73, 75, 77, 79, 81, §349.4]
