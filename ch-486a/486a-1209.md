# 486A.1209 Penalty for signing false document.
(1) A person commits an offense if that person signs a document the person knows is false in any material respect with intent that the document be delivered to the secretary of state for filing.
(2) An offense under this section is a serious misdemeanor punishable by a fine not to exceed one thousand dollars.
Source note: 98 Acts, ch 1201, §68, 79, 82
