# 425.6 Waiver by neglect.
If a person fails to file a claim or to have a claim on file with the assessor for the credits provided in this subchapter, the person is deemed to have waived the homestead exemption and credit for the year in which the person failed to file the claim or to have a claim on file with the assessor.
