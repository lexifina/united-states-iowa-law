# 428.2 Listing property of another.
Any person required to list property belonging to another shall list it in the same county in which the person would be required to list it if it were the person’s own, except as herein otherwise directed; but the person shall list it separately from the person’s own, giving the assessor the name of the person or estate to which it belongs.
