# 587.1 Decrees against unknown claimants.
All decrees of court obtained in actions against unknown defendants in which the notice was entitled in the initial or initials of the plaintiff instead of the plaintiff’s full given name are legalized, and the decrees have the same force and effect as if the notice had been entitled in the full name of the plaintiff as was provided for in section 3538, Code of 1897, and in section 3538 of the supplement to the Code of 1913.
