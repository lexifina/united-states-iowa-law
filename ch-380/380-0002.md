# 380.2 Amendment.
An amendment to an ordinance or to a code of ordinances must specifically identify the ordinance or code, or the section, subsection, or paragraph to be amended, and must set forth the ordinance, code, section, subsection, or paragraph as amended, which action is deemed to be a repeal of the previous ordinance, code, section, subsection, or paragraph amended.
