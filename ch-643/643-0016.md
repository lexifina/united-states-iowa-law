# 643.16 Assessment of value and damages — right of possession.
The jury must assess the value of the property and the damages for the taking or detention thereof, whenever by their verdict there will be a judgment for the recovery or the return of the property, and, when required so to do by either party, must find the value of each article, and find which is entitled to the possession, designating the party’s right therein, and the value of such right.
