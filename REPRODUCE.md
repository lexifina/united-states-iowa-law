## Dates

Each commit is dated at noon (America/Chicago) on the day the change took effect. The other dates, enacted and published, are trailers.

When a law gives no date of its own, the default rule applies: Oldest version available: the Iowa Code 2026 edition and the codified Constitution are the only machine-readable texts the Legislature publishes; each version is dated by the publisher own timestamp on that file. https://www.legis.iowa.gov/law/iowaCode

## How the history is built

`tools/build.py` turns the corpus into this history in one pass: one commit per law, on the day it took effect. The same corpus always gives the same commit hashes. `tools/check_repo.py` reads every version back from git and compares it with the corpus. `tools/on.py` shows the law as it stood on any date. The corpus format is described in `tools/SCHEMA.md`.

## Decisions made by hand

- No dated history is published online for the Iowa Code in machine-readable form, so each chapter is one "oldest version available", dated by the latest checkin timestamp found in the chapter XML files (the files that carry one), as the Code edition date.
- The Constitution is dated by the creation date of the Legislature codified PDF (2024-12-09); it includes Amendment 49 (2022).
- Criminal Code chapters 701 to 723A and chapter 490 (Business Corporations) were taken; property and contracts titles are not yet included.
- Footnote markers and the Legislature footnotes were dropped; the source note of each section ("history") is kept as a final line.
