# 137D.6 Conflicts with state building code.
Provisions of this chapter, including standards for home food processing establishments adopted by the department, in conflict with the state building code, as adopted pursuant to section 103A.7, shall not apply where the state building code has been adopted or when the state building code applies throughout the state.
Source note: 88 Acts, ch 1220, §12C89, §170C.6C91, §137D.62004 Acts, ch 1086, §39; 2016 Acts, ch 1086, §7; 2022 Acts, ch 1129, §6
