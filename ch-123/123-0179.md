# 123.179 Wine permit and license fees.
(1) The annual permit fee for a class “A” wine permit that is not issued to a native wine manufacturer is seven hundred fifty dollars.
(2) The annual permit fee for a class “A” wine permit issued to a native wine manufacturer is one hundred dollars.
(3) The fee for a charity beer, spirits, and wine special event license is one hundred dollars.
(4) The fee for a wine auction permit is one hundred dollars.
Source note: 85 Acts, ch 32, §70; 2003 Acts, ch 143, §13, 17; 2010 Acts, ch 1031, §86; 2013 Acts, ch 51, §2; 2019 Acts, ch 113, §53, 54; 2020 Acts, ch 1114, §3; 2022 Acts, ch 1099, §13, 15; 2024 Acts, ch 1088, §5
